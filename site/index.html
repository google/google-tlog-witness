What is this?

This site is the home of Google's transparency log witness programme. It publishes the log origins that Google makes available for witness cosigning, and coordinates the witness configurations used by log operators and verifiers.

The canonical source of truth is the google-tlog-witness GitHub repository, which contains:

  • Log lists — the set of Google-operated transparency log origins published for witness discovery, following the log-list format.
  • Witness configurations — endpoints and keys for witnesses that cosign Google's log checkpoints, following the tlog-policy format.
  • tlog-policy files — generated policy files consumed by log operators and verifiers.
